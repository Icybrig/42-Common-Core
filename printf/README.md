# Printf
This activity has been created as part of the 42 curriculum by lfang

Aiming on learning how to use the printf function in C programming language, this project is a reimplementation of the printf function. Consisting of the combination of print single characters, strings, pointers, decimal numbers, integers, unsigned decimal numbers, hexadecimal numbers in both lowercase and uppercase formats, and percent signs.

## Description
• %c Prints a single character.
• %s Prints a string (as defined by the common C convention).
• %p The void * pointer argument has to be printed in hexadecimal format.
• %d Prints a decimal (base 10) number.
• %i Prints an integer in base 10.
• %u Prints an unsigned decimal (base 10) number.
• %x Prints a number in hexadecimal (base 16) lowercase format.
• %X Prints a number in hexadecimal (base 16) uppercase format.
• %% Prints a percent sign.
